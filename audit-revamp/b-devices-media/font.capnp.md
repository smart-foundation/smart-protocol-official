# audit: `schema/font.capnp` (859 lines)

## Verdict
**FIX (targeted).** font.capnp has two coexisting interfaces — the flat legacy `Font` (font.capnp:195-204) and the session-based `FontSession` (font.capnp:51-188) — which is exactly the "old flat + new Session" pattern DESIGN_PRINCIPLES.md:211-217 says to deprecate, and unlike buffer/compositor/windowmanager this file **never marks `Font` as deprecated** (font.capnp:192-193 says only "Ordinals 0-6 preserved exactly as-is"). It also gets the forward-compat *shape* right in one place and wrong everywhere else: `FontEvent` has a proper `custom @8 :UnknownFontEvent {typeId, payload}` (font.capnp:549, 553-556) — the doctrine-exact variant — while `FontEventKind` is a 9-value enum used as a filter that can never express an unknown event. Most importantly, `FontWidth` (font.capnp:222-233) and `FontStretch` (332-343) are **verbatim duplicates of each other**, `FontStyle.weight :UInt16` (216) and `FontDescriptor.weight :FontWeight` (304) are two encodings of one quantity, and `FontAccessibilityOptions`/`FontCacheConfig.evictionPolicy`/`setHintingPreference` are global, unscoped settings on a service whose own handshake claims "One session per application" (font.capnp:48-49).

## Wire-breakers
- **None.** No compile errors, no ordinal collisions (verified mechanically).

## Duplicates & overlaps
- `FontWidth` ≡ `FontStretch` (same file, same values).
- `FontStyle` vs `FontDescriptor` — two font-request encodings, one with numeric weight, one with buckets.
- `FontFamily` (font.capnp:211-214) vs `FontFamilyEntry` (347-355); `FontInfo` (242-247) vs `FontFaceEntry` (367-376) — each pair is an "old flat" and "new rich" version of the same concept, with `Font.path` and `FontFaceEntry.file` both carrying paths.
- `GlyphInfo` (266-278) vs `GlyphMetrics` (462-473) — two glyph-metric structs with largely overlapping fields, used by `Font.getGlyphInfo @5` and `FontSession.getGlyphMetrics @10` respectively.
- `FontFamilyEntry.languages @3 :List(Text)` and `FallbackChain.language @0 :Text` and `ScriptFallbackChain.language @1 :Text` — three language spellings against `T.Language` (which console.capnp:198 uses correctly).
- `FontMetrics` (251-264) is shared by both interfaces — the one type correctly reused.
- `T.FontId` is used everywhere (font.capnp:448-450 documents the removal of the local definition) — correct, and worth noting as a resolved duplicate.

## Gaps & holes
- **No global-setter scoping.** `setHintingPreference @33`, `setAccessibilityOptions @35`, `setCacheConfig @30`, `setFallbackChain @13` and `clearFontCache @32` mutate shared state with no session, app or workspace parameter. Two concurrent clients (a text editor wanting full hinting, a browser wanting none) cannot coexist. Concrete fork: each backend invents either per-session state or a global last-write, so identical clients behave differently depending on the backend. High fork risk, cheap to fix (add the scoping key).
- **No session teardown.** `FontSession.handshake @0` mints a `T.SessionId`, but there is no `endSession`/`close` and no statement of what happens to `LoadedFont` handles when a session disappears — so the font cache can be pinned forever by an app that crashed.
- **No `unknown` on `FontEventKind`-based filtering**: `FontEventFilter.kinds @0 :List(FontEventKind)` (font.capnp:523) cannot select `custom` events, and a client filtering by kind will silently never see backend-specific events.
- **No font security/signature contract**: `FontStreamSource.url @0 :T.Uri` (font.capnp:793) fetches fonts over the network with `mimeType @1 :Text`, `headers @2 :T.StringMap` and **no signature, hash or integrity field**, while `ModuleDesc.manifest`/`LoadSpec.verifySignature` (module.capnp:118) exist elsewhere. A streamed font is unauthenticated code loaded into every text renderer.
- **No shaper contract**: `matchFont`/`loadFont` return fonts, but shaping (the complex-script/ligature/OpenType-layout part, which is where 2046 script support actually lives) is never specified — `OpenTypeInfo.featureTags` is advertised and `FontFeature` is settable on a descriptor, but no method performs shaping. Every backend invents its own shaper contract.
- **`listFontDirectories @17`/`scanFontDirectories @18`** exist but there is no event for a font appearing in a directory that is not on the scan path, and `DirectoryScannedEvent` carries a full `FontDirectory`.

## Zero-cost / eco
- **`FontFaceEntry.openType @6 :OpenTypeInfo`** with `tables :List(Text)`, `languageTags :List(Text)`, `scriptTags :List(Text)`, `featureTags :List(Text)` (font.capnp:386-391) plus `variableAxes @5 :List(VariableAxis)` (373) — every one of these lists is embedded in `FontFaceEntry`, which is embedded in `FontMatch` returned by `matchFonts @6` and in every `FontInstalledEvent`. Concrete cost: a match query returning 50 faces × (say 30 tables + 30 scripts + 100 feature tags) ships thousands of `Text` strings per search. Fix: return tags only on `getFaceInfo @4`, or behind a `FontFaceRef` (cf. ai.capnp:430-434's DocumentRef pattern).
- **`FontMatch` carries both `descriptor @0 :FontDescriptor` and `face @1 :FontFaceEntry`** (font.capnp:420-421) — and `FontFaceEntry.descriptor @0` already contains the descriptor, so the same data ships twice per match.
- `FontSubsetResult.data @0 :T.DataHandle` (font.capnp:779) is correct — a subset font is bulk and is a buffer reference. `FontStreamSource.url :T.Uri` avoids inline font bytes. R2 is otherwise satisfied.
- **Idle-power**: `getHintingPreference @34`, `getCacheConfig @31`, `getAccessibilityOptions @36`, `getLicense @24`, `getSynthesisCapabilities @25` are per-font/global getters with no caching protocol and no change events; a 2046 text stack that queries them per layout keeps the font service warm. The subscription exists (`FontEventStream`) but has no minimum-interval rule.

## UX / implementer guidance
- `FontSession.getFaceInfo @4 (descriptor :FontDescriptor) -> (face :FontFaceEntry, found :Bool)` returns a `found :Bool` instead of a `T.Error` — so "not found", "not supported" and "ambiguous match" are indistinguishable.
- `loadFont @7 → (font :LoadedFont, result :T.VoidResult)` returns a struct *and* a result — so a caller must check the result to know whether `font` is meaningful, a pattern repeated at `getFontMetrics @9`, `getGlyphMetrics @10`, `getKerning @11`, `loadFontFromStream @29`.
- `setVariationAxis @22 (fontId, tag :Text, value :Float32)` accepts a free-text axis tag with no defined spelling (`wght`? `Weight`?) and no reference to the `VariableAxis` list that `getVariationAxes @21` returns (whose `tag` is also free text).
- `HintingPreference.targetDpi @3 :UInt32` (font.capnp:838) is a DPI where `T.Resolution` exists (types.capnp:836).
- `EmojiInfo.skinTones @1 :UInt32` (a count) and `flags @3 :List(Text)` (free-text flag names) are unspecified shapes with no registry.
- `findFamily @2 → (family :FontFamilyEntry, found :Bool)` and `findFont @1 (query :FontQuery) → FontInfo` (the legacy interface) use two different "found" conventions across the two interfaces.

## Recommended actions
1. **Delete `FontStretch`, keep `FontWidth`; replace `FontStyle.weight :UInt16` and `FontDescriptor.weight :FontWeight` with one numeric field** (`UInt16`, OpenType `wght`) and remove the `FontWeight` enum. Gain: one spelling, and a variable font at wght=350 becomes expressible (it is not, today); removes a verbatim duplicate enum and a numbering continuum frozen into buckets. Cost: one enum deleted, one field retyped — pre-release, ordinal-neutral.
2. **Deprecate `interface Font`** in favour of `FontSession`, exactly as DESIGN_PRINCIPLES.md:211-217 does for buffer/compositor/windowmanager. Gain: one interface, one "found"/error convention; removes two parallel type families (`FontFamily`/`FontFamilyEntry`, `FontInfo`/`FontFaceEntry`, `GlyphInfo`/`GlyphMetrics`). Cost: ordinals preserved for wire compat; the flat API becomes a documented shim or is deleted pre-release.
3. **Scope the global setters to the session** (add the session/app id to `setHintingPreference`, `setAccessibilityOptions`, `setFallbackChain`, `setCacheConfig`, or make them per-session by construction). Gain: two clients with different hinting/accessibility needs stop clobbering each other — the highest fork-risk gap in the file. Cost: one scoping key per method.
4. **Add a session teardown** (`endSession`/`close` plus defined `LoadedFont` lifetime). Gain: a crashed app no longer pins the font cache. Cost: one method.
5. **Add `unknown` to `FontQueryRequest`/`FontQueryResult` and make `FontEventKind` an open token** (or at least document that unknown values are ignored, per ai.capnp:43-47). Gain: a backend can report an event kind the client does not know instead of overloading `familyAdded`. Cost: one variant / a type change.
6. **Add integrity to `FontStreamSource`** (a hash or signature field, delegating to crypto/signature.capnp). Gain: a streamed font stops being unauthenticated code loaded into every renderer. Cost: one field.
7. **Slim the match payload**: return face summaries (not full `OpenTypeInfo`/`variableAxes`) from `matchFonts @6`, and delete `FontMatch.descriptor @0` as a duplicate of `face.descriptor`. Gain: removes the dominant copy cost in the file — thousands of tag strings per font-match query. Cost: one field removed + one summary struct.
8. Leave `FontEvent`'s `UnknownFontEvent` shape, `FontMetrics`' font-unit documentation, `T.FontId` usage and `FontSubsetResult.data :T.DataHandle` alone: they are the parts of this file that are already right.
